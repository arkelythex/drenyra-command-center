# Arkelythex brand home image generation — 2026-05-22

## Direction

Generated a complete realistic, premium image set for the Arkelythex brand home.

Design constraints:

- Dark graphite / black system with restrained amber, teal, green, and warm-white accents inspired by premium Anduril/OpenAI-style campaign imagery.
- Realistic enterprise/fiscal infrastructure scenes, not generic SaaS illustrations.
- No readable UI text, no third-party marks, no fake brand names.
- Safe dark overlay zones for the existing captions rendered by the app, without dead black margins or letterboxed padding.
- Hero/product images exported at 1920×1080 WebP.
- Ecosystem tiles exported at 1200×900 WebP.
