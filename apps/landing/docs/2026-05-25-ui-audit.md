# UI Audit: Arkelythex Landing Pages

## Scope
Homepage + 7 product pages (Seguridad, Cortex, Ledger, Studio, Gov, Grid, Sire)

## Methodology
Evaluated against `ui-design` skill principles: anti-patterns, design language, typography, spacing, card patterns, per-page identity, micro-interactions.

---

## Critical Issues (Must Fix)

### 1. Generic dot-grid on EVERY page (Anti-pattern #7)
**Impact:** Every single page uses the exact same dot-grid background:
```css
radial-gradient(circle, rgb(255 255 255) 1px, transparent 1px)
background-size: 24px 24px
```
**Why it's bad:** Makes every page feel identical at a glance. Users can't distinguish pages by hero alone.
**Fix per page:**
- Homepage: Remove dot-grid. Use subtle noise texture or plain dark.
- Seguridad: Remove dot-grid. Security page should feel solid/grounded, not techy.
- Cortex: Keep but make amber-tinted dots, not white. Or use horizontal signal lines.
- Ledger: Replace with subtle vertical lines (ledger lines / accounting paper feel).
- Studio: Replace with soft radial mesh gradient (growth/organic).
- Gov/Grid/Sire: Remove entirely — roadmap/sales pages should be clean.

### 2. `font-display` (Cinzel) misused on Cortex
**File:** `cortex-page.tsx:45`
```tsx
<h1 className="... font-display text-display-ds font-black ...">
```
**Why it's bad:** Cinzel is a decorative display font. Using it for a product headline breaks readability and feels medieval, not engineering.
**Fix:** Remove `font-display`. Use Inter (`font-sans`) with `font-bold` or `font-black`.

### 3. Inconsistent hero layout across pages
**Issue:** No two pages have the same hero structure:
- Seguridad: badge → h1 (gradient emphasis) → subhead → NO CTAs
- Cortex: badge → h1 (amber span) → subhead → CTAs + ProductPanel
- Ledger: eyebrow text → h1 (teal span) → subhead → CTAs
- Studio: eyebrow → h1 (violet span) → audience pills → subhead → CTAs

**Why it's bad:** Users lose orientation. Each page feels like a different site.
**Fix:** Standardize hero pattern:
```
badge/eyebrow (tagline)
headline + accent span
subhead
CTAs (primary + secondary)
```
Only vary: accent color, background treatment, and optional right-side media (panel/diagram).

### 4. Missing CTAs on Seguridad hero
**File:** `seguridad-page.tsx`
**Issue:** The hero has a tagline, headline, subhead... but NO call-to-action buttons. The first CTA is at the bottom of the page.
**Fix:** Add primary + secondary CTAs to the hero, same pattern as other pages.

### 5. Hardcoded text in Seguridad certifications
**File:** `seguridad-page.tsx:95`
```tsx
title="Certificaciones verificadas"
```
**Why it's bad:** Not from `SEGURIDAD_COPY`. Copy drift risk.
**Fix:** Add `headline` field to `certBadges` in copy file and consume it.

## Important Issues (Should Fix)

### 6. Card pattern monotony on all pages
**Issue:** Every section uses `rounded-2xl border landing-border bg-background p-6 shadow-sm`. The same card 20+ times across the site.
**Fix per page (mix 2-3 patterns):**
- Use **Bordered Ghost** for secondary lists
- Use **Elevated Surface** for primary cards
- Use **Gradient Edge** for ONE featured card per page
- Use **Minimal Line** for process steps / timelines

### 7. Inconsistent button styles
**Examples:**
- Cortex: `btn-primary` + `rounded-xl bg-primary` + custom amber glow
- Ledger: `rounded-lg bg-primary px-6`
- Studio: `rounded-lg bg-primary px-6`
- Seguridad: `btn-primary` only in CTA

**Fix:** Create 2-3 standard button variants and use consistently:
1. Primary: `bg-primary text-primary-foreground`
2. Secondary: `border border-border/40 bg-secondary/20`
3. Accent (per page): `bg-{accent}-500 text-white`

### 8. Missing disabled button treatment on Gov/Grid/Sire
**Issue:** Disabled CTAs use `opacity-80` which looks like a loading state, not disabled.
**Fix:** Use `cursor-not-allowed`, desaturated color, or `bg-muted text-muted-foreground`.

### 9. Hero backgrounds lack differentiation
**Current state:**
- All pages: radial dot-grid + colored glow
- Gov/Grid: dot-grid + blue/cyan glow (improved but still dot-grid)

**Fix:** Give each page a truly unique hero background:
- Seguridad: Solid dark with subtle top-edge glow (security = solid)
- Cortex: Horizontal signal bars pattern (intelligence = data)
- Ledger: Vertical faint lines (accounting = ledger paper)
- Studio: Soft organic radial gradient (growth = organic)
- Homepage: Clean dark, no pattern (clarity = confidence)

### 10. Section spacing inconsistencies
**Examples:**
- Seguridad hero: `py-24 md:py-32 lg:py-36`
- Cortex hero: `pb-20 pt-32 md:pb-28 md:pt-40`
- Ledger hero: `py-28 md:py-36`
- Studio hero: `py-28 md:py-36`

**Fix:** Standardize to `py-24 md:py-32` for all heroes. Standardize section padding to `py-20 md:py-28`.

### 11. Icon containers lack custom treatment
**Issue:** Most icon boxes use the same pattern: `rounded-xl border border-{accent}-500/20 bg-{accent}-500/10` with `h-12 w-12`. This is okay but can be better.
**Fix:** Vary icon treatments:
- Some pages: larger icons (h-14 w-14) with stronger borders
- Some cards: icons on left side of card instead of top
- Some sections: inline icons without containers (for lists)

### 12. Missing signature elements
**Current signature elements:**
- ✅ Seguridad: architecture diagram
- ✅ Cortex: signal flow diagram
- ✅ Ledger: trace timeline
- ❌ Studio: no unique visual (just icon grid + checklist + timeline)
- ❌ Gov: no unique visual
- ❌ Grid: no unique visual
- ❌ Sire: no unique visual (but wedge page is different by design)
- ❌ Homepage: no unique visual

**Fix:** Add one signature element per page:
- Studio: studio workspace mockup or multi-RUC diagram
- Gov: governance flow diagram (policy → approval → audit)
- Grid: data pipeline diagram (API → transform → store)
- Homepage: ecosystem diagram or hero media slot

## Minor Issues (Polish)

### 13. Inconsistent border radii
- Most cards: `rounded-2xl`
- Command view (Cortex): `rounded-3xl`
- Some buttons: `rounded-xl`, others: `rounded-lg`

**Fix:** Use `rounded-2xl` for cards consistently. Use `rounded-lg` for buttons. Reserve `rounded-3xl` for special hero containers only.

### 14. `GradientText` overuse
- Seguridad hero: headline uses GradientText (good)
- Seguridad CTA: uses GradientText for tagline (okay)
- No other page uses gradient text

**Fix:** Keep gradient text on hero H1 only. Remove from CTA taglines.

### 15. Missing `prefers-reduced-motion`
**Issue:** ScrollReveal animations may not respect reduced motion.
**Fix:** Ensure all animation components check `prefers-reduced-motion`.

## Recommended Refactor Order

1. **Fix Critical issues first** (items 1-5): Remove/replace dot-grid, remove `font-display`, standardize heroes, add missing CTAs
2. **Standardize components** (items 6-7): Unify card patterns and button styles
3. **Differentiate heroes** (item 9): Give each page unique hero background
4. **Add signature elements** (item 12): Create diagrams for Studio/Gov/Grid
5. **Polish** (items 10-15): Spacing, radii, motion, gradients
