# Tutorials

**Last updated:** 2026-07-29
**Audience:** New users
**Prerequisites:** [Getting Started](../10-development/getting-started.md)

---

These tutorials guide you through Drenyya step by step. They assume nothing — each command is explained, each screen is shown.

| Tutorial | What you will learn | Time |
|---|---|---|
| [Your First Workspace](./your-first-workspace.md) | Create a workspace, explore the Workbench, understand scope. | 15 min |
| [Your First Review](./your-first-review.md) | Review a Change Set, verify evidence, approve and watch execution. | 20 min |
| [Interpret a Receipt](./interpret-a-receipt.md) | Read a receipt, verify integrity, trace to source, export for audit. | 10 min |

---

## How to use tutorials

1. Start with [Your First Workspace](./your-first-workspace.md) — it builds the context for everything else
2. Follow [Your First Review](./your-first-review.md) — it uses the workspace you created
3. End with [Interpret a Receipt](./interpret-a-receipt.md) — it uses the Change Set you reviewed

Each tutorial ends with "What You've Learned" and "Next Steps" linking to the next one.

---

## Suggested order

```text
Your First Workspace → Your First Review → Interpret a Receipt
```

After completing all three, you will understand Drenyra's core workflow: **scope → propose → review → execute → verify**.
