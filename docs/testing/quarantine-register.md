## Rules

1. Every entry MUST have all 6 columns filled.
2. Deadline MUST be within the current milestone (M1).
3. Tests past deadline SHALL be fixed or deleted within the next sprint.
4. No test stays quarantined indefinitely.
5. Review this register at each sprint planning.
