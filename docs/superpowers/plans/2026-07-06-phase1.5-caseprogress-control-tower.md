# Phase 1.5 — Agent Bar Replacement & Control Tower Detail

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the detailed per-agent status bar with an aggregated CaseProgress component, and add the detailed per-agent view to Control Tower.

**Architecture:** (1) Create a `CaseProgress` component that shows aggregated status (e.g. "3 de 4 verificaciones completas") using the existing `AgentProgressBar` for visual progress. (2) Integrate it into `CommandCenterChatHeader` behind a dev flag. (3) Add agent-session detail to the Control Tower page, reusing existing `AgentTabBar`/`AgentTabPanel` components.

**Tech Stack:** React 19 + TanStack Router + Tailwind CSS 4 + Vitest

## Global Constraints

- Use existing `AgentProgressBar` from `apps/web/src/features/agents/AgentProgressBar.tsx` for the progress bar visualization
- Use TanStack Router `redirect` for any new routes (same pattern as Phase 1 redirects)
- Dev flag: `localStorage.getItem("DRENYRA_V2_CASE_PROGRESS") === "true"` enables the new component
- All new components get at least one test file
- Framework-free shared logic (pure functions) goes in `lib/` subdirectory
- Follow existing Tailwind 4 patterns (CSS variables: `var(--text-primary)`, `var(--surface-1)`, etc.)

```tsx
// apps/web/src/features/agents/CaseProgress.tsx
import { AgentProgressBar } from "./AgentProgressBar";

export interface CaseProgressProps {
  completed: number;
  total: number;
  status: "running" | "paused" | "completed" | "failed" | "awaiting_approval";
}

const STATUS_LABELS: Record<CaseProgressProps["status"], string> = {
  running: "Revisando...",
  paused: "En pausa",
  completed: "Completado",
  failed: "Falló",
  awaiting_approval: "Listo para tu revisión",
};

export function CaseProgress({ completed, total, status }: CaseProgressProps) {
  const progress = total > 0 ? Math.round((completed / total) * 100) : 0;

  return (
    <div className="flex items-center gap-4 rounded-xl border border-[var(--border-subtle)] bg-[var(--surface-1)] px-4 py-2.5 min-w-[200px]">
      <div className="flex-1 min-w-0 space-y-1">
        <div className="flex items-center justify-between">
          <span className="text-2xs font-semibold text-[var(--text-secondary)]">
            {completed} de {total} verificaciones
          </span>
          <span className="text-2xs font-medium text-[var(--text-tertiary)]">
            {STATUS_LABELS[status]}
          </span>
        </div>
        <AgentProgressBar progress={progress} status={status} />
      </div>
    </div>
  );
}
```

- [ ] **Step 2: Create AgentSessionsSection component**

```tsx
// apps/web/src/features/control-tower/components/AgentSessionsSection.tsx
import { useQuery } from "@tanstack/react-query";
import { Bot } from "lucide-react";
import { AgentTabBar } from "@/features/agents/AgentTabBar";
import { AgentTabPanel } from "@/features/agents/AgentTabPanel";
import { useAgentsWindowStore } from "@/features/agents/agents.store";
import { agentsListQueryOptions } from "@/features/agents/query-options";

export function AgentSessionsSection() {
  const { data, isLoading } = useQuery(agentsListQueryOptions({}));
  const sessions = data?.data ?? [];
  const selectedSessionId = useAgentsWindowStore((s) => s.selectedSessionId);
  const selectedSession = sessions.find((s) => s.id === selectedSessionId) ?? null;

  return (
    <section className="rounded-2xl border border-[var(--border-subtle)] bg-[var(--surface-1)] p-5 space-y-4">
      <div className="flex items-center gap-2">
        <Bot size={18} className="text-[var(--color-info)]" />
        <h2 className="text-sm font-bold text-[var(--text-primary)]">
          Actividad de Agentes
        </h2>
      </div>

      {isLoading ? (
        <p className="text-xs text-[var(--text-tertiary)]">Cargando sesiones...</p>
      ) : sessions.length === 0 ? (
        <p className="text-xs text-[var(--text-tertiary)]">Sin sesiones activas</p>
      ) : (
        <div className="space-y-2">
          <AgentTabBar sessions={sessions} />
          {selectedSession && (
            <div className="pt-2">
              <AgentTabPanel session={selectedSession} />
            </div>
          )}
        </div>
      )}
    </section>
  );
}
```
