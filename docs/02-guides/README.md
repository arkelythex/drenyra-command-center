## Contributing a guide

If you find yourself repeating the same task explanation, write a guide. Keep it:

1. **Goal-oriented** — what will the reader accomplish?
2. **Step-by-step** — numbered steps, concrete commands or clicks
3. **Verifiable** — how does the reader know they succeeded?
4. **Scoped** — one task per guide, nothing else
