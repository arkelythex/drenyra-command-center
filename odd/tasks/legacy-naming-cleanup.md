# Legacy naming cleanup — Command Center / Pi → Desktop / Shell

Objective: remove the retired product names (`Drenyra Command Center`, `Drenyra Pi`) from this repository's documentation, metadata and scripts so the codebase matches the renamed repositories `drenyra-console` and `drenyra-shell`.
Branch: `docs/legacy-naming-cleanup` · Delivery: single docs PR · Runner: `bun`

## Specs

- **S1** — `Drenyra Command Center` and every case variant of "command center" used as a product name must not appear in tracked documentation, metadata or scripts. Replacement text: `Drenyra Console`.
- **S2** — The retired harness name `Drenyra Pi` / `drenyra-pi` must not appear in tracked documentation. Replacement text: `Drenyra Shell` / `drenyra-shell`.
- **S3** — Repository URLs and package metadata must point at `arkelythex/drenyra-console`, never `arkelythex/drenyra-command-center`.
- **S4** — Historical records are excluded from S1/S2: `odd/tasks/**` (past task logs), `CHANGELOG.md`, and git history keep their original wording.
- **S5** — No link may break: every relative link and referenced filename must still resolve after the change.
- **S6** — Structural identifiers are in scope (authorized 2026-10-27, see L10): directory and file names, exported identifiers, the web shell-mode and nav-section literals, npm script names and asset filenames must use `desktop` / `drenyra-console` / `drenyra-shell`. **Excluded:** database migration files and their journal tags (`0006_drenyra_command_center`) — renaming an applied migration breaks migration history.
