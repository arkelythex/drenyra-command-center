# ADR-0009: Operations and reliability baseline

## Status
Accepted

## Decision
Adopt an operations baseline with:
- explicit SLOs and error budgets
- incident severity model and response runbooks
- on-call responsibilities
- baseline alerts and dashboards
- postmortem template for Sev-1/2 incidents

## Why
Open-source civic platforms need predictable reliability and accountable incident handling.

## Consequences
- Maintainers must sustain operational reviews, not only feature delivery.
- Reliability work is planned as first-class backlog with measurable targets.
