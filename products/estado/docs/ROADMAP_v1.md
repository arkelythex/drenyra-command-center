# Roadmap v1

## Phase 0 (2-4 weeks): Foundation
- Governance: CONTRIBUTING, SECURITY, templates
- Architecture baseline: DDD + Hexagonal, ADRs, threat model
- Pick 1 MVP problem statement

## Phase 1 (6-10 weeks): Dual MVP track (Municipal-first)
Run in parallel:
A) Municipal spending transparency dashboard (audit-first)
B) Citizen report + evidence + verification workflow

Optional later:
C) Procedures assistant (bot-first) using official sources

Deliverables:
- API + DB schema + audit log
- Read models (search/dashboard)
- Basic UI + bot channel
- Observability stack

## Phase 2 (Pilot): 1 municipality / 1 region
- Data agreements and open data alignment
- Operational playbook (moderation, verification, incident response)

## Phase 3 (Scale): "Brigades" model
- Local chapters per region
- Standardized templates for replication
- Shared design system and reusable components
