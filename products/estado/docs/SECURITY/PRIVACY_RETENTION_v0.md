# Privacy and Retention v0 (Peru context)

Guiding law: Peru Law 29733 (personal data protection).

## Principles
- PII minimization
- Purpose limitation
- Access control + logging
- Explicit retention rules

## v0 policy
- Evidence blobs: default retention X days unless escalated by policy
- Reporter contact: optional, encrypted, segregated
- Public feed: always redacted, no sensitive fields
