# Design Thinking (Engineer-grade)

We ship hypotheses, not vibes.

## Artifacts required for an MVP
1) Problem Statement (1 page)
2) User Journey (table)
3) Hypothesis and Metrics
4) Service Blueprint (frontstage/backstage)
5) Risks and mitigations (privacy, abuse, bias)

## Metrics examples
- Activation: percent users completing first action
- Time-to-resolution (for verified reports)
- Verification rate
- False positive/negative rates (moderation)
- Cost per resolved case
