# RFCs

Request for Comments (RFCs) capture significant technical or product decisions before implementation.

## When to write an RFC
- API contract changes
- Data model or migration strategy changes
- Auth/security/privacy model changes
- New subsystem introduction
- Changes with operational impact

## File naming
- `RFC-XXXX-short-title.md`
- Example: `RFC-0001-auth-oidc-keycloak.md`

## Lifecycle
- `Draft`
- `Review`
- `Accepted`
- `Rejected`
- `Superseded`

## Template
Use `docs/RFCS/RFC-TEMPLATE.md`.
